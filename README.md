## About CipherPic

CipherPic is a privacy-focused image vault built with Flutter.

Features include:

- Local AES-256 encrypted storage
- Multiple secure vaults
- Password-protected images
- Invisible & visible watermarking
- Secure sharing (.cps format)
- Hidden & Decoy Vaults
- Duress PIN & Duress Images
- Camouflage Mode
- Screenshot protection
- Clipboard Vault
- Secure Notes
- Password Vault
- Activity & Access Logs
